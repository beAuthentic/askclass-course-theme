# Ontology Studio Cloud (가칭) — 엔터프라이즈 온톨로지 SaaS 기획 패키지

> 솔트룩스 엔터프라이즈 온톨로지 사업 강화를 위한 **신규 셀프서비스 SaaS**의
> 모듈 리스트, 핵심 요구사항, ROI 모델, 그리고 Claude Code로 바로 개발을 시작할 수 있는
> 프롬프트 모음입니다. 리뷰 후 승인된 항목부터 `03-claude-code-prompts.md`의 프롬프트를
> Claude Code에 순서대로 투입하면 됩니다.

제품명 "Ontology Studio Cloud"와 코드명 `osc`는 가칭입니다. 브랜드 결정 후 일괄 치환하세요.

## 인터뷰에서 확정된 결정 사항

| # | 항목 | 결정 |
|---|---|---|
| 1 | 배치 형태 | **별도 신규 클라우드 SaaS(멀티테넌트)**. Knowledge Studio는 백엔드 SOR로 연결 |
| 2 | 첫 경험 | **샘플 도메인 체험**으로 시작 (1차 제조 BOM, 2차 금융 상품/규제) |
| 3 | 가입 | **회사 이메일로 즉시 가입**, 개인 메일 도메인 차단, 영업 승인 없음 |
| 4 | 과금 | **기본료 + 데이터 규모 + 사용량** 혼합 |
| 5 | Knowledge Studio 연동 | API 상세 **미확인** → 어댑터 계층을 두고 SPARQL 1.1 표준만 가정 |
| 6 | ROI 기준선 | **온톨로지 없이 운영 중인 기업**과 비교 |
| 7 | LLM | **외부 API(Claude) 우선**, 교체 가능한 추상화 (향후 Luxia 대체 가능) |
| 8 | 기술 스택 | Next.js + TypeScript / FastAPI(Python) / PostgreSQL / Redis 워커 / Cytoscape.js |
| 9 | 1차 범위·기간 | **4주 공개 베타**, 풀스택 0.5명 + 온톨로지 전문가 파트타임 |
| 10 | 1차 필수 | 셀프서비스 트라이얼 + ROI 계산기 (NL2SPARQL·품질평가는 샘플 도메인 위 데모 수준) |

## 리스크 고지 (리뷰 시 반드시 확인)

- **4주 × 0.5 FTE ≈ 80시간**입니다. P0 10개 모듈은 Claude Code가 코드의 90% 이상을 생성하고 사람은 리뷰·결정만 한다는 가정입니다. 3주차 말 기준으로 M08(미터링)과 M10(문서 생성)은 컷라인 아래로 내릴 수 있게 설계했습니다.
- Knowledge Studio 실제 연동은 P2입니다. 베타는 내장 트리플스토어(Oxigraph)로 동작하고 어댑터 인터페이스만 동일하게 유지합니다.
- ROI 기본 가정값은 업계 통계와 보수적 추정의 조합이며 **솔트룩스 실제 고객 사례로 교체**해야 신뢰도가 올라갑니다. `02-roi-model.md`에 출처 표시 컬럼을 두었습니다.

## 리뷰 절차 제안

1. 사업 책임자: `01` 우선순위표와 `02` 가격·가정값 검토, 변경 사항을 표에 직접 기입
2. 온톨로지 전문가: `01`의 M02(샘플 도메인)·M06(품질 지표)·M10(문서화) 요구사항 검토
3. 개발자: `03` 부트스트랩 프롬프트 실행 → 생성된 CLAUDE.md 확인 → 모듈 프롬프트 순차 실행
4. 매주 금요일 데모, 컷라인 재조정
